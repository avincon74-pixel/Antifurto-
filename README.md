# Antifurto (Xpanel CSI via SMS)

1. Apri la cartella in Android Studio (File > Open) e attendi la sincronizzazione Gradle.
2. Collega il telefono Android (debug USB attivo) e premi Run.
3. Nell'app: imposta numero SIM della centrale e testi SMS dal manuale
   (ON / OFF / C? sono solo esempi).
4. Concedi i permessi SMS alla prima pressione di un pulsante.

Note: Android puo' limitare i permessi SMS se l'app viene pubblicata sul Play Store;
per uso personale (APK installato da Android Studio) funziona normalmente.
